Harbor Stories v0.1
Eigener Merge-Prototyp mit unbegrenzter Energie und ohne Bezahlfunktion.

Enthalten:
- 6x6 Merge-Brett
- 3 Generator-/Itemketten
- Aufträge
- Coins, XP und Level
- lokales Autosave
- PWA-Grundgerüst

Zum lokalen Test index.html öffnen. Für Installation auf iPhone als PWA muss der Ordner über HTTPS gehostet werden.
